Self-hosted first — no SaaS forge, no cloud lock-in, one login through the Innotel stack.

🔱

Gitea — repo & development hosting

Repositories, pull requests, code review, issues and boards, wikis, releases, a package registry, and built-in Actions CI/CD — your canonical remote for every platform.

Code hosting
👨‍🍳

Chef — AI app builder

Describe an app and Chef generates the full stack — database schema, zero-config auth, file uploads, realtime UIs, background workflows — on the Convex backend it knows best.

AI codegen
⚡

Convex — self-hosted backend

The open-source reactive database and compute engine behind Chef's generated apps. SQLite on a named volume to start; Postgres/S3-ready for production. Dashboard included.

App runtime
🛰️

OmniRoute — model gateway

One OpenAI-compatible endpoint pools every provider account. Chef's codegen routes through it, so Atlas never stores vendor keys — rotate providers in one dashboard.

Models

How an app is born in Atlas

Prompt → code → your forge → your runtime.

💬 You describe an app→ 👨‍🍳 Chef generates it→ 🛰️ models via OmniRoute→ ⚡ deployed to Convex→ 🔱 source lands in Gitea→ 🚀 Actions CI ships it
Identity at every step comes from Cerulean's Authentik; secrets from Infisical; DNS + TLS from Cerulean. Built apps deploy to their owning platform — Atlas holds the source.
